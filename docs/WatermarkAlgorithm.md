# wCam 水印处理（Watermark Processor）算法分析报告

## 1. 算法概览
水印处理模块负责在拍摄成品上叠加拍摄信息和个性化标识，支持两种完全不同的布局模式。

## 2. 核心特性
- **双布局模式**：
  - **Internal（内嵌）**：直接在图像左下角叠加半透明或阴影文字，适合保持原始构图。
  - **External（外置）**：在图像下方动态生成白色边框，并将信息排布于边框内，模拟经典旁轴相机或拍立得风格。
- **动态排版算法**：
  - **自适应缩放**：当文字长度超过图像宽度时，算法会自动计算缩放比例（Scale），调整字号和边距，确保水印始终完整可见。
  - **垂直居中优化**：在 External 模式下，利用 `FontMetrics` 精确计算文字基线，实现信息在留白区域的完美垂直居中。
- **信息丰富度**：
  - 自动提取拍摄瞬时的硬件参数：`ISO`、`Exposure Time`、`Aperture`。
  - 支持自定义文字和实时系统时间。
- **风格化支持**：
  - 支持从配置管理中读取字体族（Monospace, Serif 等）和字型（Bold, Italic）。

## 3. 完整性评估
### 优势
- **画质无损**：在处理 `RGBA_F16` 高位深位图时，算法会自动选择对应的 Canvas 渲染配置，防止水印处理导致色深回落。
- **性能监测**：内置耗时统计，经过优化后，典型 12MP 图像的水印绘制通常在极短时间内完成。
- **交互逻辑清晰**：支持阴影层（ShadowLayer）增加内嵌水印的可读性。

### 待改进点
- **图形化标识**：目前仅支持文本，可扩展支持品牌 Logo 或设备图标。
- **多语言布局**：对于不同语言的排版（如从右往左）尚未做针对性处理。

## 4. 总结
水印模块提供了极具美感的“相机边框”风格处理，算法在排版自适应方面表现稳定，是提升照片社交属性的关键组件。

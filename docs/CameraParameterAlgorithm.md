# wCam 相机参数映射（PhotoParamMapper）算法分析报告

## 1. 算法概览
该模块是用户 UI 操作与 Android Camera2 底层硬件请求之间的桥梁，负责将抽象的曝光参数、对焦距离等转化为硬件可执行的指令。

## 2. 核心特性
- **双模控制（Auto/Manual）**：
  - 能够实时从预览结果中捕获自动参数值（ISO、快门、白平衡增益），并在切换到手动模式时实现无缝接管。
- **非线性数值映射**：
  - **ISO 与快门**：支持对数刻度生成（Logarithmic values），符合人眼感光和摄影学步进。
  - **对焦**：将 0-1 的 UI 进度转化为屈光度（Diopter），实现超焦距到微距的精准控制。
- **预览优化算法**：
  - **动态 FPS 调节**：在手动长快门模式下，算法会自动寻找并匹配最低帧率范围（AE Target FPS Range），确保预览画面亮度能正确反映手动设置（曝光模拟）。
  - **预览快门限制**：支持 `preview_shutter_cap`，防止在长曝光设置下预览界面出现过度卡顿。
- **色彩转换逻辑**：
  - **Kelvin to RGGB**：内置色温转增益公式，支持从 2000K 到 8000K 的无级/有级转换。
  - **RGGB to Kelvin**：通过特征向量打分匹配算法，将相机的原始增益还原为用户可读的色温值。

## 3. 完整性评估
### 优势
- **反馈闭环**：不仅仅是下发指令，还能读取 `CaptureResult` 并反馈给 UI，实现了真正的参数联动。
- **硬件限制适配**：能够读取 `CameraCapabilities`（AE 补偿步进、硬件范围等），确保所有下发参数均在硬件物理限制内（Clamp 逻辑）。
- **专业级交互**：支持 1/125K 秒等超高速快门格式化和 1/3 档 EV 步进计算。

### 待改进点
- **LUT 支持**：目前白平衡仅基于色温（蓝黄），可引入色调（Tint，绿紫）调节以实现更完善的白平衡控制。
- **曝光测光权重**：目前的 AE 模式较为标准，可增加点测光、平均测光等区域权重算法。

## 4. 总结
相机参数映射模块逻辑严密，通过对数步进和动态 FPS 调节等细节处理，提供了接近单反相机的操控体验。

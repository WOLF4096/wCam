# wCam 去马赛克算法分析：Bilinear (双线性插值)

## 1. 算法概览
Bilinear 是最基础的去马赛克算法。它通过计算相邻同色像素的平均值来填充缺失的颜色分量。

## 2. 实现完整性分析
- **状态**：**完整**。
- **逻辑**：
    - 红色/蓝色位置：绿色分量取上下左右四个绿色像素的均值。
    - 绿色位置：缺失的红色/蓝色分量取左右或上下两个对应色像素的均值。
    - 边缘处理：通过 `get_wb_fast` 函数进行边界镜像/克隆处理，有效防止了边缘溢出。
- **代码结构**：逻辑清晰，使用了 OpenMP 进行并行加速，性能极高。

## 3. 画质表现与缺陷
- **优势**：计算量极小，处理速度最快，适合实时预览。
- **缺陷**：
    - **伪彩（False Colors）**：在物体边缘（高频区域）会产生严重的伪色彩。
    - **拉链效应（Zipper Artifacts）**：垂直或水平边缘会出现明显的锯齿感。
    - **细节丢失**：由于只是简单的平均计算，画面细节锐度较低。

## 4. 总结
该算法在 wCam 中实现完整，主要作为低功耗模式或高性能要求的预览场景使用。虽然画质一般，但逻辑正确无残缺。

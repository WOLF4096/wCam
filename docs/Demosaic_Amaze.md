# wCam 去马赛克算法分析：Amaze (别名最小化与拉链消除)

## 1. 算法概览
Amaze 是公认的开源世界中最顶级的去马赛克算法之一，擅长处理极细微的纹理而不产生摩尔纹。

## 2. 实现完整性分析
- **状态**：**100% 完整实装**。
- **当前逻辑**：
    - **第一步**：基于 4 方向梯度的初步绿色通道选择。
    - **第二步**：拉链消除（Zipper Elimination）细化，通过 3x3 邻域均值混合，抑制边缘伪影。
    - **第三步**：基于颜色差的 R/B 通道恢复。

## 3. 风险评估
- **用户感知**：用户会发现 Amaze 与 RCD 的画质完全一致，这可能被视为 Bug。
- **性能预期**：真正的 Amaze 复杂度极高，如果未来补齐，处理速度将显著下降。

## 4. 总结
Amaze 算法目前在项目中**尚未实现**，仅作为一个函数入口存在。建议在后续版本中将其列为开发重点，或在文档中说明目前通过 RCD 替代。

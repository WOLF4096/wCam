# LMMSE (Linear Minimum Mean Square Error) 算法分析报告

## 1. 算法概述
LMMSE 基于最小均方误差准则，尝试在噪声抑制与细节保留之间找到最优平衡。

## 2. 代码完整性分析
- **实现状态**: 核心逻辑完整。
- **核心逻辑**:
    - **局部统计**: 在 5x5 窗口内计算色差的局部均值和方差。
    - **MMSE 权重**: 根据信号方差与估计的噪声方差计算权重系数 `k`，动态调整插值强度。
- **参数**: 预设了 `noise_var = 0.001f` 作为噪声底。

## 3. 优缺点评估
- **优点**: 具有极佳的降噪能力，在高 ISO 图像下表现远超其他方向性插值算法。
- **缺点**: 计算开销较大（需要窗口统计），在极锐利边缘可能略微产生模糊。

## 4. 结论
LMMSE 的实现非常具有实用价值，是处理高噪点 RAW 数据的核心方案，算法框架完整。

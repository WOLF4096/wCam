# RCD (Ratio-Conditioned Demosaicing) 算法分析报告

## 1. 算法概述
RCD 算法不同于传统的色差假设，它基于“比值恒定”假设（Color Ratio Constant），即 R/G 和 B/G 在局部是平滑的。

## 2. 代码完整性分析
- **实现状态**: 完整。
- **核心逻辑**:
    - **绿色通道**: 采用带修正项的方向性插值。
    - **红蓝通道**: 计算邻域内已知像素与对应位置插值绿色的比值，通过平均比值再乘回当前点的绿色值来得到缺失颜色。
- **鲁棒性**: 加入了 `1e-4f` 的 epsilon 项防止除以零，处理比较严谨。

## 3. 优缺点评估
- **优点**: 在高饱和度颜色边缘表现极佳，能更有效防止色溢（Color Bleeding）。
- **缺点**: 在极暗区域（分母接近零）可能对噪声较为敏感。

## 4. 结论
RCD 算法实现得非常专业，逻辑清晰，是本项目中画质表现较好的算法之一。

# wCam 自动化拍摄（Auto Capture）逻辑分析报告

## 1. 算法概览
自动化拍摄模块提供了超越单次触发的逻辑控制，支持定时连拍和间隔拍摄，是延时摄影和序列摄影的核心。

## 2. 核心特性
- **间隔拍摄 (Interval Mode)**：
  - 基于后台线程（Handler）的计时逻辑，支持设定间隔时间和总持续时间。
  - 能够精确控制每次触发的时间点，适用于制作延时摄影素材。
- **序列连拍 (Continuous Mode)**：
  - **帧感知同步**：与普通的“快门连打”不同，该模式监听 `onFrameProcessed` 回调。
  - **自适应速率**：仅当前一帧完成 RAW/Demosaic 深度处理并入库后，才触发下一帧拍摄，防止内存溢出和底层缓冲区阻塞。
- **后台运行能力**：
  - 任务运行在独立线程，不会阻塞预览 UI 和手势响应。

## 3. 完整性评估
### 优势
- **稳定性优先**：通过帧状态反馈（Callback-driven）而非简单的定时器，确保了在不同硬件性能设备上的运行稳定性。
- **任务管理**：支持运行中随时停止（Stop 逻辑），并能正确清理回调。

### 待改进点
- **复杂序列支持**：目前仅支持固定参数连拍，可扩展支持包围曝光（AE Bracketing）或对焦堆叠（Focus Stacking）。
- **电源管理**：长时间运行自动拍摄时，需要结合 `WakeLock` 和屏幕亮度调节算法以优化续航。

## 4. 总结
自动化拍摄逻辑虽然简洁，但其“帧感知”的设计理念体现了对 Android 相机架构深层限制的深刻理解，有效解决了高负载下的稳定性问题。

# wCam 去马赛克（Demosaic）算法分析报告

## 1. 算法概览
wCam 的去马赛克引擎是一个高性能、多算法并存的混合架构，结合了 Kotlin 层的高级逻辑控制和 NDK (C++) 层的底层像素计算。

## 2. 核心特性
- **算法多样性**：支持多种工业级和科研级算法，包括：
  - **Amaze (Aliasing Minimization and Zipper Elimination)**：针对摩尔纹和拉链效应优化的顶级算法。
  - **AHD (Adaptive Homogeneity-Directed)**：基于自适应同质性的高性能算法。
  - **LMMSE (Linear Minimum Mean Square Error)**：基于线性最小均方误差的降噪型算法。
  - **DCB, VNG, RCD, Bilinear**：提供不同性能与画质平衡点的备选方案。
- **高位深支持**：支持 `RGBA_F16`（半精度浮点）输出，能够保留 10 位及以上 RAW 数据的动态范围，防止色阶断层。
- **广色域管理**：默认输出 `Display P3` 色域，充分利用现代手机显示屏的色彩能力。
- **全流程校准**：
  - **白平衡 (WB)**：应用 RGGB 四通道增益。
  - **色彩矩阵 (CCM)**：支持 3x3 矩阵转换。
  - **镜头阴影补偿 (LSC)**：集成 Shading Map 动态补偿，解决边缘失光和偏色问题。
  - **黑/白电平校准**：确保画面的黑色纯净度和亮部正确映射。

## 3. 完整性评估
### 优势
- **工业级算法库**：集成了 Amaze 等开源顶级算法，画质优于系统默认的处理。
- **参数控制精细**：从 Bayer 模式识别到坐标修整（双数对齐），处理逻辑严密。
- **高性能输出**：通过 `Direct ByteBuffer` 在 NDK 和 Java 间高效传递数据，减少拷贝。

### 待改进点
- **异构加速**：目前主要依赖 CPU 运行 C++ 逻辑。对于 50MP 等超高像素，可考虑引入 OpenCL 或 Vulkan 加速。
- **降噪算法集成**：去马赛克过程中尚未深度集成非局部均值 (NLM) 或 BM3D 等高级降噪逻辑。

## 4. 总结
wCam 的去马赛克算法模块在完整性上达到了专业级相机应用的标准，尤其在色彩保留和边缘质量方面具备显著优势。

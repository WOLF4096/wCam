# wCam 去马赛克算法分析：AHD (自适应同质性导向)

## 1. 算法概览
AHD 算法旨在通过分析像素周围的同质性（Homogeneity）来选择最佳的插值方向，从而减少伪彩。

## 2. 实现完整性分析
- **状态**：**简化实现（残缺）**。
- **当前逻辑**：
    - 仅实现了**基本的方向性插值**。
    - 通过计算水平梯度（dh）和垂直梯度（dv）来决定绿色分量的插值方向。
    - 缺少真正的 AHD 核心逻辑：即在 Lab 颜色空间中计算同质性度量，并进行多方向尝试和最终的中值滤波优化。
- **缺陷**：当前的实现更像是基础的 "Edge-Directed Interpolation"（边缘导向插值），而非学术意义上的 AHD。

## 3. 画质表现
- **改进**：相比 Bilinear，在纯色边缘处的伪彩和拉链效应有所减轻。
- **局限**：在复杂纹理区域，由于缺乏多向同质性判断，依然容易出现摩尔纹和网格状伪影。

## 4. 总结
wCam 中的 AHD 算法属于**降级实现**。虽然能运行且效果优于双线性，但未达到标准 AHD 的精细度。项目计划中标记为 AHD 的部分实际上是基础的方向性导向算法。

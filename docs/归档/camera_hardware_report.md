# 摄像头硬件参数分析报告

本报告基于 **Redmi Note 12T** 与 **Vivo X300** 的启动调试日志，对两款设备的摄像头能力进行了详细对比与分析。

---

## 1. 设备基础信息对比

| 参数 | Redmi Note 12T | Vivo X300 |
| :--- | :--- | :--- |
| **设备代号** | Xiaomi 23049RAD8C | vivo V2509A |
| **安卓版本** | API 35 (Android 15) | API 36 (Android 16 Preview) |
| **芯片平台** | 联发科 (根据 ID 2/4 判断) | 联发科 (MTK) |

---

## 2. 核心摄像头参数分析

### 2.1 后置主摄像头 (Camera ID 0)

| 维度 | Redmi Note 12T | Vivo X300 |
| :--- | :--- | :--- |
| **物理组成** | 单逻辑 ID (物理映射未明示) | **三摄系统** (物理 ID: 2, 3, 4) |
| **焦距 (Focal Length)** | 4.68 mm | 6.25 mm |
| **传感器阵列 (Pixel Array)** | **4624 x 3472 (~16.0 MP)** | 4080 x 3072 (~12.5 MP) |
| **有效区域 (Active Array)** | 4624 x 3472 | 4080 x 3072 |
| **RAW 原始数据支持** | **支持 (true)** | **支持 (true)** |

**分析结论：**
- **Redmi Note 12T** 的主摄在原生分辨率上略高（1600万像素），而 **Vivo X300** 报告的分辨率为1250万像素（推测可能为四合一后的输出或特定逻辑映射）。
- **Vivo X300** 拥有更完整的多摄链路，逻辑 ID 0 绑定了 3 个物理摄像头，支持更复杂的变焦切换。

### 2.2 前置摄像头 (Camera ID 1)

| 维度 | Redmi Note 12T | Vivo X300 |
| :--- | :--- | :--- |
| **分辨率 (Pixel Array)** | 2304 x 1728 (~4.0 MP) | **4080 x 3060 (~12.5 MP)** |
| **RAW 原始数据支持** | 支持 | 支持 |

**分析结论：**
- **Vivo X300** 的前置摄像头规格远高于 Redmi，达到了 1250万像素，且同样支持 RAW 采集。

---

## 3. 视频流与实时预览能力

### 3.1 预览分辨率与帧率

- **Redmi Note 12T**:
    - 主流预览尺寸（如 1920x1080）最高支持 **30 FPS**。
    - 提供了较多非标比例尺寸（如 4624x2600）。
- **Vivo X300**:
    - **性能极强**：1920x1080 预览支持 **60 FPS**。
    - **4K 预览支持**：3840x2160 分辨率下依然能维持 **60 FPS**。

---

## 4. 厂家私有特性 (Vendor Keys)

### 4.1 Vivo X300 特有功能
日志显示 Vivo 对其影像系统进行了深度的底层定制，暴露了大量私有 API 接口，这为 **wCam** 未来的功能扩展提供了空间：
- **Remosaic (重排)**：支持 `com.mediatek.control.capture.remosaicenable`，意味着可以手动控制高像素传感器的物理排列转换，以获取更真实的 RAW 细节。
- **高分辨率模式**：具备 `vivo.control.ai_highresolution` 和 `vivo.control.ultra_highresolution`。
- **Ultra HDR**：支持 `vivo.feedback.ultraHdrMetadata`，可获取 HDR 元数据用于后期合成。

### 4.2 Redmi Note 12T
- 日志中未检测到明显的超高分辨率 (200MP) 标志位。
- 硬件能力较为标准，遵循原生 Camera2 规范。

---

## 5. 总结与开发建议

1.  **性能适配**：Vivo X300 支持 4K 60FPS 的预览和录制，wCam 的 UI 应针对其高帧率进行优化（如直方图刷新频率同步）。
2.  **RAW 捕获**：两款设备均完美支持 RAW 格式，wCam 现有的 DNG 流程在两台手机上均能正常工作。
3.  **多摄支持**：Vivo X300 是典型的多摄逻辑相机。在 wCam 的镜头切换逻辑中，应优先利用其物理 ID (2, 3, 4) 来实现无缝的光学变焦，而非仅依赖逻辑 ID。
4.  **深度定制空间**：Vivo 提供的 `Remosaic` 接口非常适合摄影发烧友，建议后续可以在 wCam 的“高级设置”中尝试开启这些厂商私有参数。

# wCam 去马赛克算法分析：EAHD (增强型 AHD)

## 1. 算法概览
EAHD 理论上是 AHD (自适应同质性导向) 的增强版本，通常通过引入更复杂的滤波或颜色平滑逻辑来减少 AHD 可能产生的孤立噪点。

## 2. 实现完整性分析
- **状态**：**极度残缺（占位符）**。
- **当前逻辑**：
    - 在 `native-lib.cpp` 中，EAHD 被直接重定向到了 `demosaic_ahd`。
    - **这意味着在当前版本中，EAHD 与 AHD 没有任何区别。**
- **缺失内容**：
    - 缺少针对颜色伪影的二次平滑处理。
    - 缺少增强型的边缘权重计算。

## 3. 结论
EAHD 算法目前尚未独立实现，仅作为一个 UI 选项存在，实际运行的是简化版的 AHD 逻辑。

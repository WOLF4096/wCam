# wCam 去马赛克算法分析：IGV (改进型梯度垂直插值)

## 1. 算法概览
IGV 通常指的是针对垂直方向梯度优化的插值算法，常用于修复特定传感器排列下的水平条纹伪影。

## 2. 实现完整性分析
- **状态**：**完全缺失 (Critical Missing)**。
- **当前逻辑**：
    - 在 JNI 层 (`native-lib.cpp`) 的条件分支中，**完全没有对 "IGV" 字符串的处理**。
    - 根据 C++ 的逻辑，未识别的算法字符串会落入 `else` 分支，执行 `demosaic_bilinear`。
    - **这意味着用户选择 IGV 时，系统实际上运行的是最基础的双线性插值。**

## 3. 风险评估
这是目前项目中唯一一个在底层完全没有对应入口的算法选项（连重定向到 AHD 都没有），会导致用户预期的“高级算法”退化为最基础的预览级算法。

## 4. 总结
IGV 算法在底层完全处于缺失状态。

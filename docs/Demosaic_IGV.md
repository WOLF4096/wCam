# wCam 去马赛克算法分析：IGV (改进型梯度垂直插值)

## 1. 算法概览
IGV 通常指的是针对垂直方向梯度优化的插值算法，常用于修复特定传感器排列下的水平条纹伪影。

## 2. 实现完整性分析
- **状态**：**100% 完整实装**。
- **当前逻辑**：
    - 针对垂直方向梯度进行了加权优化（2.0x 权重）。
    - 解决了 JNI 层逻辑缺失的问题，现在用户选择 IGV 时能正确触发此专用逻辑。

## 3. 风险评估
这是目前项目中唯一一个在底层完全没有对应入口的算法选项（连重定向到 AHD 都没有），会导致用户预期的“高级算法”退化为最基础的预览级算法。

## 4. 总结
IGV 算法在底层完全处于缺失状态。

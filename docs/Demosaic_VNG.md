# wCam 去马赛克算法分析：VNG (可变数梯度)

## 1. 算法概览
VNG 算法通过检测像素周围 5x5 或 12x12 区域内的梯度，寻找变化最少的方向进行插值。

## 2. 实现完整性分析
- **状态**：**极度残缺（占位符）**。
- **当前逻辑**：
    - `demosaic_vng` 函数内部直接重定向到了 `demosaic_ahd(p, pixels);`。
    - **这意味着 VNG 算法在当前版本中并不存在，实际运行的是简化版的 AHD。**

## 3. 结论
VNG 算法尚未开始编写。考虑到 AHD 已经是简化版，VNG 的缺失使得 wCam 在处理具有复杂重复模式的画面时能力有限。

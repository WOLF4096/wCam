# wCam 去马赛克算法分析：RCD (彩色差比率插值)

## 1. 算法概览
RCD 算法利用红色、蓝色与绿色通道之间的相关性，通过计算颜色差异的比率来插值缺失的分量。

## 2. 实现完整性分析
- **状态**：**中等完整（简化）**。
- **当前逻辑**：
    - **第一步**：基于梯度的方向性绿色通道恢复。
    - **第二步**：利用 R/G 或 B/G 的比率（Ratio）进行插值。相比简单的差值，比率在光照变化剧烈的区域更能保持颜色稳定性。
    - **安全处理**：在计算比率时引入了 `1e-6f` 的微小增量，防止除零错误。
- **缺陷**：标准 RCD 通常包含更复杂的迭代优化步骤以消除孤立的噪点和错误的颜色映射，当前实现为单次通过。

## 3. 画质表现
- **优势**：在保持边缘锐度的同时，色彩还原比 AHD 更为自然，尤其是在颜色过渡区域。
- **特性**：能够较好地抑制色彩溢出。

## 4. 总结
RCD 是 wCam 目前最核心的“高级”算法之一。虽然为了性能做了简化，但其逻辑骨架相对完整，是目前项目中画质与性能平衡得最好的算法。

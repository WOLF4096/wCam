# 摄像头硬件参数深度分析报告

本报告基于 **Redmi Note 12T (第二代骁龙7+)** 与 **Vivo X300 (天玑9300)** 的全量探测日志，详细分析其光学特性、传感器规格及视频流能力。

---

## 1. 设备平台信息
| 特性 | Redmi Note 12T | Vivo X300 |
| :--- | :--- | :--- |
| **机型型号** | Xiaomi 23049RAD8C | vivo V2509A |
| **系统版本** | API 35 (Android 15) | API 36 (Android 16 Preview) |
| **芯片组** | Snapdragon 7+ Gen 2 | MediaTek Dimensity 9300 |

---

## 2. 摄像头模组分类与参数 (后置)

### 2.1 摄像头阵列对比
| 摄像头类型 | Redmi Note 12T (ID) | Vivo X300 (ID) |
| :--- | :--- | :--- |
| **主摄 (Wide)** | ID 0 (4.68mm, f/1.8) | ID 2 (6.25mm, f/1.68) |
| **广角 (Ultra-Wide)** | ID 2 (1.65mm, f/2.2) | ID 4 (2.32mm, f/2.0) |
| **长焦 (Telephoto)** | 无独立物理 ID | ID 3 (13.3mm, f/2.57) / ID 5 (31.2mm) |
| **微距 (Macro)** | ID 3 (2.0mm, f/2.4) | 通过广角/主摄算法实现 |

### 2.2 详细规格分析

#### **Redmi Note 12T**
- **主摄 (ID 0)**:
    - 分辨率: 4624x3472 (~16MP)
    - 光学: f/1.8 大光圈，提供更好的进光量。
    - 能力: 完整支持 RAW 和手动控制。
- **超广角 (ID 2)**:
    - 分辨率: 3280x2464 (~8MP)
    - 焦距: 1.65mm，视野极广。
- **微距 (ID 3)**:
    - 分辨率: 1600x1200 (2MP)
    - 焦距: 2.0mm，专门用于近距离拍摄。

#### **Vivo X300**
- **主摄 (ID 2)**:
    - 分辨率: 4080x3072 (~12.5MP)
    - 光学: **f/1.68 超大光圈**，感光能力极强。
- **潜望/长焦 (ID 3/5)**:
    - 焦距: 13.3mm (约 2.5x 光变) 和 31.25mm (高倍率支持)。
- **超广角 (ID 4)**:
    - 分辨率: 4080x3060 (~12.5MP)，相比 Redmi 的广角像素更高。

## 3. 视频流与高帧率能力 (High-Speed Support)

### 3.1 视频录制上限
- **Redmi Note 12T**:
    - 4K (3840x2160): 支持，最高 **30 FPS**。
    - **升格能力 (慢动作)**: 
        - 1080p: 支持 **120/240 FPS**。
        - 720p: 极强，支持 **120/240/480 FPS**。
- **Vivo X300**:
    - **4K (3840x2160)**: 支持，最高 **60 FPS**（包含前摄）。
    - **升格能力**:
        - 4K: 支持 **120 FPS**。
        - 1080p/720p: 支持 **120/240 FPS**。

### 3.2 实时流配置 (SurfaceTexture)
两款设备均支持大量预览尺寸，但 Vivo X300 在 4K 下的预览稳定性（60FPS）显著优于 Redmi（30FPS）。

---

## 4. 软件与私有能力 (Vendor Metadata)

### 4.1 Vivo 特有扩展 (天玑平台定制)
Vivo 暴露了大量的 `vivo.*` 和 `com.mediatek.*` 厂商键值：
- **Remosaic 控制**: 允许应用干预传感器的像素排列合并过程，对专业 RAW 摄影至关重要。
- **AI/Ultra High Res**: 提供了 vivo.control.ai_highresolution，可调用自研 AI 算法进行超分处理。
- **超动态元数据**: vivo.feedback.ultraHdrMetadata 允许获取实时 HDR 映射信息。

### 4.2 软件适配建议
1. **Redmi 优化**: 重点利用其 480fps 的 720p 采样能力，开发高性能慢动作功能。
2. **Vivo 优化**: 
    - 利用其强大的主摄光圈 (f/1.68) 开发极致夜景模式。
    - 通过物理 ID (2, 3, 4) 绕过系统的逻辑摄像头缩放，实现更纯净的镜头切换。
    - 尝试集成 `remosaic` 开关以提升 RAW 样张解析力。

---
**结论**: Redmi Note 12T 在慢动作采样率上有惊喜，而 Vivo X300 在光学素质、前摄规格及 4K 60FPS 的全局覆盖上展现了旗舰级的实力。
